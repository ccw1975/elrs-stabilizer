一、功能概述
----------------------------------------------------------------
本固件在 ExpressLRS 接收机基础上集成了固定翼姿态自稳功能:

  - 姿态传感器:MPU6500(陀螺仪 + 加速度计)
  - 姿态解算:Mahony 互补滤波(500Hz 姿态环)
  - 三种介入模式(模式开关三档实时切换,见下):
      * 直通(Bypass):纯杆量,自稳完全不介入(默认安全档)
      * Rate        :横滚纯角速度阻尼,松杆刹停旋转、不强制回平
      * Angle       :横滚回平(目标坡度跟随摇杆,收敛柔和)
  - 俯仰轴:全模式直通(升降舵纯杆量,不介入、跟手)
  - 输出修正:在舵机 PWM 上叠加修正量
      Angle:限幅 ±30° 等效 ×5us/度 = ±150us,再经收敛系数 0.7 → 实际 ±105us
            (约 ±10% 满行程)
      Rate :限幅 ±180us(约 ±18% 满行程,LUA 可调 0~255)
            另含死区 8°/s(低于此角速度不介入)与输出低通(α=0.35),
            用于抑制抖舵与左右晃动
  - 三级安全:模式低档(直通)/传感器异常/信号丢失 均自动旁路

通过遥控器的 LUA 菜单调参,通过遥测回传实时观察姿态与输出。

二、LUA 菜单(Stabilizer)
----------------------------------------------------------------
进入路径:遥控器系统菜单 → Lua Tools → ExpressLRS 接收机脚本
  → Stabilizer 文件夹

菜单共 11 项,说明如下:

[1] Airframe —— 机身布局
    Normal : 普通布局(副翼 + 升降舵独立)
    Wing   : 飞翼布局(elevon 混控由遥控器完成;自稳只输出横滚差动
             —— PWM1=+roll、PWM2=-roll,两片反向,不同向)
    默认:Normal

[2] Aileron —— 副翼舵机数量
    1 Servo : 单副翼(Y 线/机械联动),CH6 无修正
    2 Servo : 双副翼,CH6 输出差动副翼修正
    默认:1 Servo

[3] Gain Switch —— 模式开关通道(三档实时切换,不存档)
    CH1~CH12 任选一路;用三档开关控制介入模式:
      低档(< 约 1/3 行程)→ 直通(纯杆量,自稳退出;默认安全档)
      中档           → Rate(横滚纯阻尼,刹停旋转、不强制回平)
      高档(> 约 2/3 行程)→ Angle(横滚回平)
    无信号/未收到通道值 → 按直通处理
    默认:CH5
    注意:模式实时读取开关位置,上电/断连总在安全档直通;
    若只用两档开关,则只有"直通 / Angle"两档可用。

[4] IMU —— 传感器状态(只读)
    1 = 传感器正常,自稳可用
    0 = 传感器异常/未就绪,自动旁路(此时任何模式都不介入)
    上电后应先确认此项为 1 再飞行

[5] Roll Kp —— 横滚比例增益(Angle 模式,角度误差→修正力度)
    范围 0~25,显示值 ×0.1 为实际增益
    默认 10(即 1.0)。调大则回平更"硬",过大易震荡

[6] Roll Kd —— 横滚微分增益(角速度阻尼,仅 Angle 档使用)
    范围 0~50,显示值 ×0.01 为实际增益
    默认 5(即 0.05)。调大抑制快速摆动/震荡
    注:Rate 档的阻尼强度由 [7] Rate Gain 独立控制,与本项无关
       (修改点 24 起两档参数彻底解耦,各调各的)

[7] Rate Gain —— Rate 档阻尼增益(角速度→舵量)
    范围 0~30,显示值 ×0.1 为实际增益(us 每 °/s)
    默认 8(即 0.8)。调大刹停更硬,过大易过冲晃动(wag)
    只作用于 Rate 档,不影响 Angle 档手感

[8] Rate Limit —— Rate 档修正限幅
    范围 0~255,单位 us
    默认 180(≈±18% 满行程)。是 Rate 档舵量的硬上限,
    晃动压不下来时优先降这项

[9] Rate Dead —— Rate 档死区
    范围 0~30,单位 °/s
    默认 8。角速度低于此值完全不介入;超出后按(ω−死区)线性输出。
    作用:滤掉陀螺噪声与手抖引起的舵面微动(静止抖舵就调大它)

[10] Roll Dir —— 横滚轴修正方向
    Normal : 正向
    Rev    : 反向(仅翻转 IMU 修正方向)
    默认:Normal
    用途:治"摇杆方向都对、但自稳叠加方向反了"。最常见是
    传感器装反(绕机头轴转了 180° 等)→ 横滚自稳反了,拨 Rev。

    说明:
    - 本开关只翻转 IMU 修正方向,不影响摇杆直通方向;
    - 与通道映射页的 Invert 完全独立、互不干扰:
        Invert    治"舵机接线反、打杆方向反"(直通+修正一起翻)
        Roll Dir  治"传感器装反、自稳方向反"(只翻修正)
    - 按"轴"设置而非按"通道":普通布局差动副翼(CH6=-roll)、
      飞翼差动(+roll/-roll)的结构符号由固件自动保持,翻一个
      开关即可让横滚所有相关通道一起翻转,无需逐通道设置。
    - 俯仰已全模式直通,不再需要 Pitch Dir(菜单已隐藏)。

[11] 6CH Rev —— CH6(左副翼)直通反向
    Normal : 正向
    Rev    : 反向(仅翻转 CH6 直通信号,绕中位)
    默认:Normal
    用途:普通布局 + 2 副翼舵机时,若左右舵面同向,
    把此项拨到 Rev 即可让 CH6 反向,左右舵面变差动。
    只翻直通信号,自稳修正(差动 -roll)不受影响;
    与通道映射页 Invert(直通+修正一起翻)完全独立,
    与 Roll Dir(只翻修正)也互不干扰。

    说明:
    - 生效条件:Airframe=Normal + Aileron=2 Servo + 本项=Rev,三条件齐;
    - 左副翼舵机必须插在 PWM6 输出口(硬件 GPIO21),不是 PWM1;
    - 若同时把映射页 CH6 勾了 Invert,两者在直通上会双重翻转
      互相抵消,修正也被 Invert 翻转,整个开关等于失效——两者互斥,
      用本开关时请把 CH6 的 Invert 恢复为 Normal。

修改即时生效,并自动保存到接收机 EEPROM,断电重启后保留。
若想恢复出厂,可在遥控器 ELRS 脚本里对接收机执行默认配置恢复。

----------------------------------------------------------------
LUA 调参建议:
  1. 首次装机用默认值(10 / 5)飞,先确认修正方向正确;
  2. 若"摇杆方向对、自稳方向反"(常见于传感器装反):
       - 机体向右滚 → 右副翼应上翘、左副翼下压(把机身压回水平)。
       反了就把 Roll Dir 拨到 Rev,再试;
     (俯仰已直通,无需/无法调俯仰修正方向)
  3. 先飞 Angle 档:逐步加大 Roll Kp 到机体出现轻微来回摆动(震荡),
     然后加大 Roll Kd 把震荡压掉,直到"稳而不抖";
  4. Angle 修正已内置收敛系数(0.7),回平比旧版柔和、不抢杆;
  5. Angle 修正输出上限约 ±150us(等效 ±30°),Kp 再大也只是更快
     达到上限,不会无限增强;
  6. Rate 档(修改点 24 起三项参数可调,与 Angle 档互不干扰):
     默认 Rate Gain 0.8 / Rate Limit 180us / Rate Dead 8°/s。
     调参按现象对症:
       - 仍左右晃动(wag)、过冲     → 先降 Rate Gain(0.8→0.5),
                                     还晃再降 Rate Limit(180→120);
       - 刹不住、旋转停得太慢      → 加大 Rate Gain(0.8→1.2),
                                     或加大 Rate Limit;
       - 静止/小动作时舵面抖、微动 → 加大 Rate Dead(8→12°/s);
       - 舵面动作突兀、不跟手      → 降 Rate Limit;
     试飞确认"阻尼方向正确、松杆能刹住旋转"即可。
     (输出低通 α=0.35 为固件固定值,不占用菜单)

三、遥测回传(观察姿态与输出)
----------------------------------------------------------------
本固件回传 CRSF Attitude 遥测(10Hz),EdgeTX 端操作:

  模型设置 → 遥测 → Discover Sensors(发现传感器)
  → 出现 Attitude 传感器(Roll / Pitch / Yaw 三项)

三项含义:

  Roll  : 实测横滚角。晃动机体实时变化,静止归零
  Pitch : 实测俯仰角。同上
  Yaw   : CH1 实际输出 PWM(us,已含自稳修正)
          ※ 本固件不关心航向,Yaw 字段被复用来回传 CH1 输出
          范围约 988~2012us,中位约 1500

在遥测屏只添加 Roll、Pitch 两项即可看姿态;
想验证自稳输出就添加 Yaw 项(CH1 输出)。

----------------------------------------------------------------
姿态数值的单位与读数说明(重要):
  EdgeTX 的 Attitude 传感器按 CRSF 协议规定显示"弧度"而非角度:
    - 显示 1.57 ≈ 90°,显示 3.14 ≈ 180°
    - 想读角度:数值 × 57.3 即可(如 1.5 × 57.3 ≈ 86°)
    - 姿态仪 widget(仪表盘)内部已换算,显示的姿态角正确
    注:接收机按协议发送弧度值,这是标准行为,不是故障。

  以下均属正常现象,不要据此调参:
    - Roll 转到 180° 附近:读数跳到 -3.14 / +3.14,
      是角度显示的回绕(±180° 边界),继续转回落到 0;
    - Pitch 转到垂直(90°):读数到 1.57 后继续转会"回落",
      是反正弦定义域只有 ±90° 的反射,正常;
    - Pitch 接近 90° 时 Roll 读数快速增长到 ±3.14:
      这是欧拉角的"万向节锁定"(Gimbal Lock)——俯仰竖立
      时横滚与航向变得无法区分,是姿态表示方法的固有特性,
      所有用欧拉角的飞控都有此现象。
      修改点 23 起,Angle 模式已内置"重力参考可靠度"衰减:
      机头越接近竖直,角度项权重越小(|gzE|<0.30 即约 72° 起
      开始让位,90° 完全退化为纯阻尼)——横滚读数爆炸时角度
      项已接近 0,不会乱打舵,只剩方向永远正确的阻尼。
      这不会在正常飞行触发:平飞/正常坡度可靠度≈1,手感不变。

----------------------------------------------------------------
验证 IMU 是否真实参与通道调整(Angle 档):
  1. 模式开关拨高档(Angle),摇杆中位;
  2. 看 Yaw(CH1 输出),静止时应约 1500;
  3. 把机体绕机头轴拨到固定坡度(如 15°)并保持:
       - CH1 输出偏离 1500,偏得越多说明修正越强
       - 同一角度下,调大 Roll Kp 后偏离明显增大 → Kp 生效
       - 松开机体回到水平,CH1 快速回到 1500 附近
     → 满足以上现象,说明 IMU 修正确实叠加到了通道输出。
  Rate 档验证:把机体快速绕机头轴旋转一下然后松手,
    应能感到修正"刹住"旋转(方向与转动相反),但不会把
    机身拉回水平——与 Angle 档的差别一眼可辨。

五、Telem Ratio(遥测比率)建议
----------------------------------------------------------------
位置:发射机 LUA 菜单(不是接收机菜单)

  调试/验证阶段 : 1:8   (姿态与 CH1 输出满速刷新,LUA 调参流畅)
  日常飞行      : 1:16  (姿态仍接近实时,带宽占用小)
  不需要看姿态  : 1:64  (官方默认,链路最稳)

  说明:姿态遥测本身限速 10Hz,高于 1:16 的档位不会让姿态
  显示更快,只提升 LUA 菜单响应;数值越大的档位(1:64/1:128)
  LUA 调参基本不可用。

六、使用注意事项
----------------------------------------------------------------
1. 三级安全(默认设计,不要关闭):
   - 上电默认直通,模式开关低档/无信号时不介入;
   - 传感器异常(IMU 显示 0)自动旁路;
   - 信号丢失自动旁路,交给原有 failsafe。
2. 首次使用务必地面测试:
   - 确认 IMU 显示 1;
   - 确认横滚修正方向与姿态相反(向右滚,修正应压回水平);
   - 方向反了会变成正反馈,立即切直通档检查;
   - 若摇杆方向正确但自稳方向反:先检查传感器是否装反,
     重新安装即可,零代码;确实无法重装时,再用 Roll Dir 拨 Rev;
   - 飞翼布局确认 Airframe=Wing(自稳只出 roll 差动,
     PWM1=+roll / PWM2=-roll,两片反向),Aileron 数量正确。
3. 陀螺仪零偏在每次上电时静态校准(约 100ms),
   上电时请保持机体静止。
4. 震动大的飞机(油机/多旋翼)不建议开启本自稳。
5. 方向修正规范(自稳通道:副翼):
   - 用接收机 LUA 通道映射页的 Invert 调方向;
   - 不要在发射机端反向(目标角符号会反,打杆时自稳会
     朝错误方向帮忙,任何 Invert/Dir 组合都救不回)。
